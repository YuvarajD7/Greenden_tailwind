# # 🌿 Greenden – Plant Store Website

Greenden is a responsive plant-store website designed to provide a clean, modern, and nature-inspired shopping experience. The project is built using **HTML and Tailwind CSS** with a responsive layout for desktop, tablet, and mobile devices.

## 🌱 Features

* Responsive navigation bar
* Hero section with call-to-action buttons
* Featured plant products
* Product cards with images, names, categories, and prices
* Why Greenden section
* Plant-care information
* Promotional CTA section
* Responsive footer
* Mobile navigation menu
* Smooth scrolling
* Hover animations and interactive UI elements

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **Unsplash / Pexels** for plant images

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/greenden-website.git
```

### 2. Open the project

```bash
cd greenden-website
```

### 3. Run the website

Open:

```text
greenden.html
```

in your browser.

You can also open the project in **VS Code** and use the **Live Server** extension.

## 🎨 Design

The website uses a green and white color palette inspired by nature. The design focuses on:

* Clean typography
* Rounded cards
* Large plant photography
* Minimal navigation
* Responsive layouts
* Nature-inspired colors

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

Tailwind CSS responsive utilities are used to adapt the layout to different screen sizes.

## 🌿 Featured Products

The website currently includes:
